# Humans & Characters

Stores player, pedestrian and NPC character assets.

## Add here

- Player character models.
- Pedestrian and civilian NPC models.
- Character clothing, hair and accessories.
- Animation clips, rigs and character materials.

Document rig type, skeleton compatibility, scale, forward axis, animation names and texture dependencies. Keep reusable animations organized. Character AI, navigation and interaction logic belong in game systems rather than static asset files.
