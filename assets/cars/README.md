# Cars & Vehicles

Stores vehicle models and vehicle-specific resources for the GTA '96 world.

## Add here

- Cars, sedans, hatchbacks and SUVs.
- Baby taxis / auto-rickshaws and cycle rickshaws.
- Buses, trucks, vans and emergency vehicles.
- Vehicle-specific wheels, interiors, materials and variants.

For each vehicle, document its display name, model file, category, approximate dimensions, wheel positions, forward axis, origin, collision shape and texture dependencies. Keep driving physics and vehicle behavior in game code. Prefer optimized GLB/GLTF models with mobile-friendly geometry and textures.
