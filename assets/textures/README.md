# Shared Textures & Materials

Stores reusable texture maps and material resources shared by multiple asset categories.

## Add here

- Base color / albedo maps.
- Normal, roughness, metallic and ambient-occlusion maps.
- Decals, atlases and reusable surface patterns.

Use descriptive filenames and document resolution, color space, map type, intended material and source/license. Keep model-specific textures with their model when they are not shared.
