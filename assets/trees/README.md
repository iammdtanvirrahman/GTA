# Trees & Vegetation

Stores natural environment assets used across streets, parks, yards and roadside areas.

## Add here

- Street trees and large shade trees.
- Palms, coconut trees and other regional species.
- Shrubs, hedges, grass and ground vegetation.
- Potted plants and decorative vegetation.

Use descriptive names. Document approximate height, canopy width, pivot/origin, LOD availability and whether the asset supports instancing. Prefer optimized models for repeated vegetation and mobile performance.
